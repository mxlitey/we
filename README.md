# 微信公众号私信推送飞书 Webhook

将微信公众号收到的私信实时推送到飞书群机器人。

## 部署

### 1. 安装依赖

```bash
npm install
```

### 2. 配置环境变量

| 环境变量 | 说明 | 必填 |
| --- | --- | --- |
| `WX_TOKEN` | 微信公众号后台设置的 Token | 是 |
| `WX_ENCODING_AES_KEY` | 微信公众号消息加密密钥 | 是 |
| `WX_APP_ID` | 微信公众号 AppID | 是 |
| `FEISHU_WEBHOOK_URL` | 飞书机器人 Webhook 地址 | 是 |
| `PORT` | 服务监听端口（腾讯云 EO Pages 会自动注入） | 否，默认 9000 |

### 3. 启动服务

```bash
npm start
```

### 4. 腾讯云 EO Pages 部署

在 EO Pages 项目设置中添加上述环境变量，构建命令填 `npm install`，启动命令填 `npm start`。

### 5. 微信公众号配置

在微信公众号后台「设置与开发 - 基本配置」中，服务器地址填写：

```
https://你的域名/wechat
```

Token 和 EncodingAESKey 与环境变量保持一致，消息加解密方式选择「安全模式」或「兼容模式」。

## 接口说明

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/wechat` | 微信服务器验证 |
| POST | `/wechat` | 接收微信消息并推送飞书 |
| GET | `/health` | 健康检查 |

## 飞书推送格式

收到微信私信后，飞书收到的消息格式：

```
【微信公众号私信】
发送者: oXXXXXX
时间: 2026/6/7 12:00:00
文本消息: 用户发送的内容
```

支持的消息类型：文本、图片、语音、视频、位置、链接、事件等。
